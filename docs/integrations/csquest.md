# CSGamifications → FlowQuest

FlowQuest เป็นแอปหลัก ใช้ React router, บัญชี, session, PostgreSQL และ XP ของ FlowQuest ร่วมกัน ไม่มีบริการ CSGamifications แยกหรือหน้าล็อกอินที่สอง

## ส่วนที่นำมาใช้

- บทเรียน ป.5 จำนวน 4 โลก 51 ด่าน พร้อมเกมเรียงลำดับ สั่งหุ่นยนต์ จัดหมวดหมู่ แผนภูมิ สถานการณ์จำลอง และกิจกรรมจากคู่มือ
- แผนที่ การปลดล็อกด่าน หัวใจ คำใบ้ และการตรวจคำตอบฝั่งเซิร์ฟเวอร์
- ภารกิจสร้างผลงาน สมุดสะท้อนคิด การส่งฉบับแก้ไข และข้อเสนอแนะจากครู
- หน้าติดตามผลและดาวน์โหลดคะแนน XLSX สำหรับนักเรียนที่ครูมีสิทธิ์ดูแล

เข้าเมนู **ผจญภัย ป.5** จากแถบด้านข้าง หรือ `/csquest` หลังเข้าสู่ระบบ FlowQuest และกลับหน้าหลักด้วยปุ่ม **กลับ FlowQuest**

## การเชื่อมข้อมูล

- ใช้บัญชีใน `users` เดิม ไม่สร้างบัญชีหรือรหัสผ่านอีกชุด
- ใช้ API `/api/v1/csquest/*` พร้อม Bearer token และการต่ออายุ/ยกเลิก session ของ FlowQuest
- เก็บความก้าวหน้าในตาราง `cs_progress`, `cs_attempt`, `cs_learning_work`, `cs_work_submission` ที่เชื่อมกับ `users.user_id`
- เมื่อผ่านด่าน เพิ่มเฉพาะส่วนต่างคะแนนที่ดีที่สุดลง `points_history` โดยใช้ source `csquest` การส่งผลซ้ำหรือเล่นซ้ำด้วยคะแนนเท่าเดิมไม่เพิ่ม XP
- คะแนนภายในหน้าผจญภัยเป็นคะแนนเฉพาะกิจกรรม ป.5 ส่วนโปรไฟล์ FlowQuest แสดง XP รวมตามระบบเดิม
- ครูดูผล/ตรวจผลงานได้เฉพาะนักเรียนในรายวิชาที่เป็นเจ้าของ ส่วน super admin ดูได้ทั้งหมด นักเรียนเห็นอันดับเฉพาะห้องของตน นักเรียนที่ยังไม่มีห้องเห็นเฉพาะตนเอง
- บทเรียนชุดนี้เป็นคลังกลาง ยังไม่ใช่ด่านที่ครูเปิด/ปิดเป็นรายวิชา การปลดล็อกใช้ลำดับการเรียนของคลัง
- ไม่ย้ายบัญชี รหัสผ่าน หรือประวัติผู้เรียนจากฐานข้อมูล CSGamifications เดิมอัตโนมัติ เพราะยังไม่มีการจับคู่กับบัญชี FlowQuest

## ติดตั้งบนสภาพแวดล้อมอื่น

```sh
docker compose build backend frontend
docker compose run --rm --no-deps backend flask --app run db upgrade
docker compose up -d backend frontend
```

## ผลตรวจล่าสุด (20 กันยายน 2026)

- PostgreSQL ผ่าน 5 กรณีทดสอบ รวมเฉลยครบทุกด่าน การให้ XP ซ้ำ สิทธิ์ครู แฟ้มผลงาน และ migration
- ชุดทดสอบหน้าเว็บเดิมผ่าน 29 รายการ และ build หน้าเว็บ/Docker ผ่าน
- Chrome: นักเรียนขนาด 1440 และ 390 พิกเซล เปิดบทเรียน เล่นครบ 3 ภารกิจ ผ่านด่าน และเล่นซ้ำได้; หน้าครูแสดงนักเรียนในรายวิชาที่รับผิดชอบ ไม่พบ JavaScript error
- หลังเปลี่ยนหน้าผลลัพธ์เสร็จ ความสูงเนื้อหาตรงกับหน้าจอ ไม่มีพื้นที่ว่างค้างจากเอฟเฟกต์คลิก
- เครื่องพัฒนานี้อัปเดตฐานข้อมูลถึง `a819csquest` และเปิด backend/frontend เวอร์ชันรวมแล้ว หน้า `/csquest` ตอบ 200 และ API ที่ไม่มี token ตอบ 401
- การตรวจในเบราว์เซอร์ใช้บัญชีสมมติและฐานข้อมูลทดสอบแยก ไม่เพิ่มประวัติการเล่นให้บัญชีนักเรียนจริง

## ครูรีเซ็ตการเล่นรายด่าน

ในหน้า **ห้องเรียนของฉัน** กด **ดูความคืบหน้า** ของนักเรียน แล้วกด **รีเซ็ตด่าน** ข้างด่านที่ต้องการ ระบบแสดงชื่อนักเรียนและด่านพร้อมผลที่จะถูกล้างก่อนยืนยัน

- ล้างผลผ่าน คะแนนดีที่สุด เห็ด และหักคืน XP เฉพาะด่านนั้นด้วยรายการปรับคะแนน ทำซ้ำไม่หักคะแนนซ้ำ
- ยุติรอบที่กำลังเล่นและกันการส่งผลจากรอบเก่าหลังรีเซ็ต เริ่มรอบใหม่ได้ตามสิทธิ์การปลดล็อกเดิม
- เก็บสถานะอ่านบทเรียน ผลด่านอื่น และแฟ้มผลงานเดิม ประวัติการเล่นเก่าเปลี่ยนเป็น **ครูรีเซ็ต** และไม่นับในสถิติการเล่นปัจจุบัน
- ด่านถัดไปที่ยังไม่เคยเริ่มอาจถูกล็อกจนผ่านด่านที่รีเซ็ตอีกครั้ง ตามลำดับบทเรียนเดิม
- เก็บผู้รีเซ็ต นักเรียน ด่าน จำนวนรอบ และ XP ที่หักคืนไว้ใน `activity_logs`
- จำกัดสิทธิ์เหมือนหน้าติดตามผล ครูต่างรายวิชาและนักเรียนไม่สามารถเรียกใช้การรีเซ็ตได้

เพิ่มชุดทดสอบ PostgreSQL รวมเป็น 9 กรณี ครอบคลุมการรีเซ็ตด่านเดียว การคงข้อมูลอื่น การเล่นซ้ำ การป้องกันรีเซ็ตซ้ำ และการส่งผลพร้อมกับรีเซ็ต

การส่งออกคะแนนเป็น `flowquest-grade5-scores.xlsx` มีคอลัมน์เลขที่ เรียงเลขที่แบบตัวเลขจากน้อยไปมาก ผู้ที่ไม่มีเลขที่อยู่ท้ายรายการ รวมคะแนนสะสมและคะแนนทุกด่าน จำกัดตามสิทธิ์ครูและห้องเรียนที่เลือก ส่วนเลขที่ซ้ำเรียงห้องเรียนและรหัสบัญชีเป็นลำดับรอง
