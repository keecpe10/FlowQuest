# นำเข้ารายชื่อนักเรียนส่วนกลางจาก XLSX

ผู้ดูแลระบบ (Super Admin) เข้า **จัดการนักเรียน (ส่วนกลาง) → นำเข้า XLSX** แล้วดาวน์โหลดแม่แบบ กรอกข้อมูลในชีตแรก เลือกไฟล์ กด **ตรวจสอบรายชื่อ** และ **ยืนยันนำเข้า**

| คอลัมน์ | การกรอก |
| --- | --- |
| เลขที่ | จำนวนเต็มบวก จำเป็นต้องกรอก |
| ชื่อผู้ใช้ | ไม่ซ้ำกับบัญชีใดในระบบ ไม่เกิน 50 ตัวอักษร |
| รหัสผ่าน | 6–128 ตัวอักษร ระบบบันทึกเป็น password hash |
| ชื่อ, นามสกุล | จำเป็นต้องกรอก ไม่เกินช่องละ 100 ตัวอักษร |
| ห้องเรียน, ระดับชั้น, ปีการศึกษา | กรอกครบทั้งสามช่อง หรือเว้นว่างทั้งหมด |
| อีเมล | ไม่บังคับ ถ้ากรอกต้องเป็นอีเมลและไม่ซ้ำ |

รองรับสูงสุด 1,000 แถวต่อไฟล์ ขนาดไม่เกิน 5 MB ใช้หัวคอลัมน์แถวแรกตามแม่แบบ (หรือชื่อ field ภาษาอังกฤษที่ตรงกัน) ไม่รับสูตร Excel ชื่อผู้ใช้และรหัสผ่านควรเป็นชนิดข้อความเพื่อรักษาเลขศูนย์นำหน้า

ตรวจทั้งไฟล์ก่อนสร้างบัญชี ถ้าข้อมูลผิดหรือซ้ำจะแจ้งเลขแถวและยังไม่บันทึกทั้งหมด ไม่แก้ไขบัญชีเดิม การยืนยันนำเข้าตรวจข้อมูลซ้ำอีกครั้งและบันทึกใน transaction เดียว พร้อมสร้างห้องเรียนที่ยังไม่มี

`users.student_number` เป็นจำนวนเต็มที่เว้นว่างได้สำหรับบัญชีเดิม เพิ่ม/แก้ไขรายคนและค้นหาได้ในหน้าส่วนกลาง ไม่ใช่เลขรหัสนักเรียนหรือชื่อผู้ใช้ Migration `c920_student_number` ต่อจาก `a819csquest`

การทดสอบ: `docker compose run --rm --no-deps -e CSQUEST_TEST_POSTGRES=1 backend python -m unittest test_student_import test_csquest -v` ใช้ schema ชั่วคราวแยกจากข้อมูลจริง รวม 16 กรณี ตรวจการนำเข้า การไม่เปิดเผยรหัสผ่านในการ preview การ rollback เลขศูนย์นำหน้า สิทธิ์ และ migration
